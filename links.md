## Project

- [GitHub](https://github.com/rc-kid/rckid): source for the SDK, firmware, apps, and this website.
- [Hackaday.io](https://hackaday.io/project/205276-rckid): project page with build logs.
- [OSHWLab](https://oshwlab.com/zduka/rckid-iii/): open hardware, schematics and PCB of the mkIII board.

## Documents

- [Vision](https://github.com/rc-kid/rckid/blob/main/VISION.md): the story behind the project and where it is going.
- [Programming ladder](https://github.com/rc-kid/rckid/blob/main/LADDER.md): design of the language and editors.
- [Hardware](https://github.com/rc-kid/rckid/blob/main/HARDWARE.md): hardware overview and design notes.
- [Cartridges](https://github.com/rc-kid/rckid/blob/main/CARTRIDGES.md): the cartridge system and available cartridges.
- [SDK](https://github.com/rc-kid/rckid/blob/main/SDK.md): writing software for the device.
